# Landing Page

This project was made as part of the [Landing Page assignment](https://www.theodinproject.com/lessons/foundations-landing-page) from The Odin Project.

The task was to recreate a webpage from a provided design using HTML and CSS. I kept the main structure, but I changed the content and added my own style instead of making it look exactly the same.

I added my own images, hover effects, wave dividers, gradients and a larger footer. I also changed some of the sections to make the page feel more personal.

## What I Practiced

- Writing and organizing HTML
- Building layouts with Flexbox
- Using reusable containers
- Styling buttons, images and navigation links
- Adding hover effects and transitions
- Working with spacing, alignment and typography
- Using Git and GitHub during the project

## Reflection

I had a lot of fun with this project. It was nice to start with a basic design and slowly turn it into something that felt more like my own.

I especially enjoyed working on the smaller details and seeing the whole page come together one section at a time.

## Future Improvements

The page is currently made mainly for desktop screens, so it is not fully responsive yet.

I plan to come back to it after learning more about responsive design and media queries, then improve it for tablets and mobile devices.
